# Система управління складом інтернет-магазину електроніки

Курсова робота з програмування.

## Опис

Вебзастосунок для управління складом інтернет-магазину електроніки.  
Система дозволяє вести облік товарів, постачальників, заявок на закупівлю, формувати звіт по залишках, керувати користувачами та переглядати журнал дій.

## Технології

- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- Bootstrap
- BCrypt.Net-Next

## Основний функціонал

- CRUD товарів
- CRUD постачальників
- CRUD заявок на закупівлю
- автоматичне оновлення залишків після виконання заявки
- захист від повторного виконання заявки
- звіт по залишках
- реєстрація та авторизація
- ролі Guest, Seller, Manager, Admin
- журнал дій користувачів
- захист паролів через BCrypt.Net-Next
